# House Price Predictor

Predicting California house prices using machine learning.

## Dataset
California Housing dataset (20,640 rows, 9 columns) from scikit-learn.

## Week 1 Progress
- Loaded data and checked for missing values (none found)
- EDA: price histogram and correlation analysis
- Finding: Median income (MedInc) has the strongest correlation with house price (0.69)
- Baseline Linear Regression model: R2 = 0.576

## Tech Stack
Python, pandas, matplotlib, scikit-learn
